Features

Placeholders
%hoshinoshard_shards% – Player balance

Commands
/shards – Show your balance, or open shop when using the shop-only alias command
/shards– Show your balance
/shards help – Show admin usage (shards.admin)
/shards give (player) (amount) – Add shards to online or offline player (shards.admin)
/shards remove (player) (amount) – Remove shards (alias take) (shards.admin)
/shards take (player) (amount) – Same as remove (shards.admin)
